# Cue-Smith

A site that teaches students to write better prompts for AI. Python and NiceGUI only.

## Rules
- Python and NiceGUI for all logic and UI, custom CSS for styling. No React, Next.js, Flutter, Streamlit or other frameworks. No Node.js, Java or C.
- Do not add dependencies without asking me first.
- JavaScript is allowed only for the custom cursor, at most 30 lines in total. Ask before adding any.
- Never read, print, open or edit .env. Never put secrets in code or chat.
- Do not edit anything in lessons/. The lesson content is mine.
- Keep the look exactly as it is (neutral grey, raised glass, Fraunces font) unless I ask for a visual change.
- Before editing, show a short plan and wait for my OK.
- After editing, explain each change in plain English: what it does and why. I need to be able to explain this project myself.
- Keep changes small. Do not rewrite working code or reformat unrelated lines.
- Do not commit or push. I do that in GitHub Desktop.
- I run the app myself with python3 main.py. Do not start servers.
